# ProductCatalog

A responsive product catalog web application built using React and Bootstrap. The application fetches product data from the DummyJSON API and displays it dynamically using reusable components.

## Features

- Product data fetching using the Fetch API
- State management using useState
- API integration using useEffect
- Dynamic product cards using .map()
- Loading and error handling
- Separate service layer for API requests
- Responsive product grid
- Product ratings, prices and stock information
- Custom navbar, footer and storefront logo
- Pastel colour scheme and card hover effects

## Technologies Used

- React.js
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- HTML and CSS
- Vite
- DummyJSON API
- Postman

## API Endpoint

https://dummyjson.com/products

Method: GET

The API endpoint was tested using Postman before integration.

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the localhost URL displayed in the terminal.
